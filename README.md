# بررسی بیومارکرهای تنباکو در پیمایش NHANES (دوره‌های ۲۰۲۱ تا ۲۰۲۳)

این مخزن شامل پروژه‌ درس آمار و کاربرد آن (دانشکده علوم ریاضی دانشگاه صنعتی شریف) است که به تحلیل مقایسه‌ای مواجهه با نیکوتین و بار فلزات سنگین ناشی از مصرف سیگار سنتی، سیگار الکترونیکی (ویپ) و مصرف دوگانه بر اساس داده‌های چرخه ۲۰۲۱ تا ۲۰۲۳ پیمایش ملی بررسی سلامت و تغذیه آمریکا (NHANES) می‌پردازد.

---

### ساختار مخزن پروژه
* **`data/`**: حاوی راهنمای داده‌ها، منبع رسمی و دستورالعمل بازتولید مجموعه‌داده تحلیلی.
* **`src/`**: اسکریپت‌ها و ماژول‌های پایتون برای بارگذاری، ادغام، ممیزی کیفیت داده، آمار توصیفی و تحلیل طرح نمونه‌گیری.
* **`notebooks/`**: نوت‌بوک‌های اجرایی گوگل کولب برای اسمبل‌کردن مراحل تحلیل و تولید خروجی‌ها.
* **`figures/`**: نمودارهای آماری استاندارد و علمی تولیدشده با کیفیت 300 DPI.
* **`reports/`**: گزارش‌های مکتوب فازهای مختلف پروژه در قالب فایل‌های LaTeX و خروجی‌های PDF.
